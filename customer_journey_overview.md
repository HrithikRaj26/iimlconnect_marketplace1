# Customer Journey Overview: IIML Connect

## The Entry Point: Dashboard
Upon logging in, the student is welcomed at the central Dashboard (`/`).
- **Personalized Onboarding:** The user is greeted by name (time-of-day specific) and a short audio chime.
- **Intent Discovery:** The user can instantly state their goal ("I want to sell my bike" or "Who delivers food?") into the Conversational AI Command Center via text or voice, which intelligently routes them to the correct section.
- **Habit Formation:** A Daily Streak widget encourages the user to return regularly.

## Journey 1: The Buyer (Marketplace)
1. **Browse & Filter:** The user navigates to the Marketplace, utilizing instant search and live side-bar filters (Category, Condition, Price) to find specific items.
2. **Evaluate:** Clicking an item opens the detailed product page to view the photo gallery, read specs, and see seller credibility.
3. **Negotiate:** The user clicks "Make an Offer", selects an amount, and adds a message.
4. **Close the Deal:** The user enters the Messages hub, negotiates via the split-screen chat and Negotiation Sidebar, and finalizes the Transaction Agreement (price, pickup location, time).

## Journey 2: The Seller (Marketplace)
1. **Initiate Listing:** Triggered via a prominent "+ Sell an Item" Floating Action Button.
2. **Wizard Flow:** The user goes through a frictionless 4-step wizard:
   - *Step 1:* Drag-and-drop photo upload.
   - *Step 2:* Enter basic item details.
   - *Step 3:* Set price and select a campus pickup location.
   - *Step 4:* Preview the live card and publish.
3. **Manage Offers:** The seller receives incoming offer cards in their chat sidebar and can visually click "Accept", "Decline", or "Counter".

## Journey 3: The Reporter (Lost & Found)
1. **Search & Report:** A student who lost an item visits the Lost & Found portal and uses voice search to check if it's already found. 
2. **Post Alert:** If not found, they use the reporting wizard to post a "Lost" card.
3. **Instant Match:** The system algorithm automatically highlights potential matching "Found" items reported by others, bridging the gap instantly.

## Journey 4: The Explorer (Student Ventures)
1. **Discover Services:** Students looking for campus services (laundry, food, gig work) browse the Student Venture Hub.
2. **Engage & Review:** They can view startup catalogs, engage in the community feed to ask questions, and leave reviews affecting the "Reputation Shelf" leaderboard.
